# 어벤져스 학습용 금융서비스 공통 안내

본 문서는 AvengersBank 학습용 서비스의 데모 약관 초안입니다. 실제 금융기관 상품의 계약 문서가 아닙니다. 금액은 데모 원화 단위이며 실제 금융상품의 수익·혜택·보호를 보장하지 않습니다.

## [scope] 적용 범위

이 문서와 상품에 연결된 종류별·개별 상품 문서를 함께 확인합니다. 거래는 데모 데이터베이스 안에서 처리됩니다. 실제 은행의 계좌, 카드망, ATM, 외화 환전과 연결된다는 의미가 아닙니다.

## [identity] 사용자와 거래 권한

로그인한 사용자는 본인 소유 계좌와 카드의 조회·변경을 요청할 수 있습니다. 사용자에게 다른 사람의 계좌 잔액이나 거래내역을 조회할 권한을 부여하지 않습니다. 수취 계좌 확인에 표시되는 이름은 데모 회원정보에 등록된 이름이며, 외부 기관이 실명을 인증했다는 뜻이 아닙니다.

## [amount-date] 금액과 날짜

거래 금액은 양의 정수로 입력하며 현재 공통 입력 상한은 1조 원입니다. 계좌 잔액, 상품별 조건, 이체 한도 및 카드 한도 검사는 별도로 적용됩니다. 일별 한도와 만기·청구 기간은 한국 표준시(KST)를 기준으로 판단합니다.

## [simulation] 제공하지 않는 실제 금융 기능

본 서비스는 실제 예금 수탁이나 실제 카드 발급을 수행하지 않습니다. 실제 예금자보호 적용, 정부 지원금 지급, 세제 혜택, 신용평가·신용정보기관 보고를 약속하지 않습니다. 상품명에 청년·트래블·프리미엄 등이 포함되어도 해당 명칭만으로 실제 제휴 혜택이 발생하지 않습니다.

## [description] 상품 소개와 실제 처리의 구분

각 상품 문서의 '소개 문구와 데모 제한'을 함께 확인합니다. 미구현이라고 명시된 할인·면제·자동이체·자격 확인 등은 제공 기능으로 해석하지 않습니다. 명시되지 않은 연회비나 수수료의 실제 금융기관 요율을 이 데모에 적용하지 않습니다.

## [assistant] AI 설명의 범위

챗봇의 설명은 해당 상품과 문서 버전의 내용을 이해하기 위한 보조 기능입니다. 챗봇이 설명했다고 약관 동의, 상품 가입, 실제 이체가 완료된 것은 아닙니다. 개인별 잔액과 거래 상태는 조회 시점에 바뀔 수 있습니다.
