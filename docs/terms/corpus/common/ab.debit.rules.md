# 어벤져스 체크카드 이용약관

본 문서는 AvengersBank 학습용 서비스의 데모 약관 초안입니다. 실제 금융기관 상품의 계약 문서가 아닙니다. 금액은 데모 원화 단위이며 실제 금융상품의 수익·혜택·보호를 보장하지 않습니다.

## [issuance] 발급과 연결계좌

체크카드 상품과 본인 입출금계좌를 선택해 발급합니다. 연결한 계좌가 결제 금액의 출금 계좌입니다. 신용카드처럼 별도의 신용 한도나 결제일을 설정하지 않습니다.

## [payment] 즉시 출금과 잔액 부족

활성 체크카드의 데모 결제를 요청하면 연결 계좌 잔액에서 이용금액 전액을 즉시 차감하고 카드·계좌 거래내역을 기록합니다. 잔액이 부족하면 결제를 거절합니다. 신용 결제로 자동 전환하지 않습니다.

## [history] 누적 사용액과 청구서

체크카드 누적 사용액은 이미 결제한 금액의 합계이며 앞으로 낼 미결제액이 아닙니다. 현재 체크카드 청구서 생성·납부 기능은 없습니다. 별도 계좌 간 이체 한도를 카드 결제 한도라고 해석하지 마세요.

## [status] 정지·재개·해지

활성 카드는 정지할 수 있고 정지 카드는 재개할 수 있습니다. 활성 또는 정지 상태에서 해지할 수 있습니다. 정지·해지 상태의 카드는 새 결제를 할 수 없으며 해지 후 재개는 지원하지 않습니다. 해지한다고 연결 계좌가 해지되는 것은 아닙니다.

## [benefits] 지원하지 않는 기능

실제 가맹점 카드망, 후불교통, 소액 신용 결제, 환전, 해외 ATM, 할인·캐시백·포인트 지급은 구현되어 있지 않습니다. 개별 카드의 소개 문구와 실제 즉시 출금 동작을 구분합니다.
