# 어벤져스 신용카드 이용약관

본 문서는 AvengersBank 학습용 서비스의 데모 약관 초안입니다. 실제 금융기관 상품의 계약 문서가 아닙니다. 금액은 데모 원화 단위이며 실제 금융상품의 수익·혜택·보호를 보장하지 않습니다.

## [issuance] 발급과 결제계좌

신용카드 상품, 본인 입출금 결제계좌, 매월 1~31일 중 결제일을 지정합니다. 한도는 발급 시 상품의 신용 한도를 카드에 복사해 저장합니다. 사용자가 발급 요청에서 임의의 신용 한도를 지정하지 않습니다. 실제 신용 심사와 실물 카드 배송은 제공하지 않습니다.

## [payment] 카드 이용과 한도

활성 카드만 데모 결제를 할 수 있습니다. 기존 미결제액과 새 결제액의 합이 카드 한도를 넘으면 결제를 거절합니다. 신용카드 사용 시 입출금계좌에서 즉시 출금하지 않고 미결제액을 늘리며 사용처·금액을 기록합니다.

## [billing] 청구서 생성

사용자가 청구 대상 연월을 지정해 청구서를 생성합니다. KST 기준 해당 달이 끝난 뒤에만 생성할 수 있고 같은 카드·같은 달에는 한 번만 생성합니다. 해당 월의 미청구 사용내역 합계가 0원이면 청구서를 만들지 않습니다. 자동 청구 스케줄러는 없습니다.

## [due-date] 납부 예정일

청구 대상 월의 다음 달에 설정한 결제일을 적용합니다. 해당 일자가 없으면 그 달 말일로 정합니다. 예를 들어 결제일이 31일인 카드의 1월 사용분은 2월 말일이 예정일입니다. 현재 공휴일에 따른 영업일 이동 처리는 없습니다.

## [bill-payment] 청구서 납부

사용자가 납부를 요청하면 결제계좌에서 청구서 전액을 출금하고 카드 미결제액을 그만큼 줄입니다. 잔액 부족 시 납부되지 않습니다. 이미 납부한 청구서는 다시 출금하지 않습니다. 결제 예정일 전에도 생성된 청구서를 납부할 수 있습니다. 자동 출금, 부분 납부, 리볼빙, 연체이자 계산은 구현되어 있지 않습니다.

## [status] 정지·재개·해지

활성 카드는 정지할 수 있고 정지 카드는 재개할 수 있습니다. 정지 또는 해지 카드로 새 결제를 할 수 없습니다. 미결제액이 남은 신용카드는 해지할 수 없습니다. 사용 정지가 기존 청구서 납부 의무나 미결제액을 없애지는 않습니다. 해지 카드는 재개할 수 없습니다.

## [benefits] 부가서비스 제한

할인·포인트·연회비 청구·해외 결제망·환전·라운지 서비스는 현재 구현되어 있지 않습니다. 개별 카드 소개 문구의 비율이나 횟수는 실제 혜택 제공을 뜻하지 않습니다. 카드론·현금서비스·할부도 지원하지 않습니다.
